# 🖥️ Azure Virtual Machines

## 📌 Overview

**Azure Virtual Machines (VMs)** provide scalable compute resources in the cloud.

A virtual machine allows you to run operating systems and applications without maintaining physical hardware.

---

## 🎯 Why Use Azure Virtual Machines?

Azure VMs can be used for:

- 🖥️ Hosting applications
- 🐧 Running Linux workloads
- 🪟 Running Windows workloads
- 🧪 Development and testing
- ⚙️ Running cloud-based services
